# SystemZen

Smart battery health and system monitoring utility with intelligent charge alerts, battery cycle management, brightness control, and real-time device insights.

---

## ✨ Features

### 🔋 Battery Health Monitoring

- Real-time battery percentage tracking
- Battery health status monitoring
- Charge/discharge analytics
- Battery cycle tracking

### ⚡ Smart Charging Alerts

- Notify when battery reaches **80%** while charging
- Notify when battery drops below **20%**
- Helps maintain long-term battery health
- Configurable notification thresholds _(planned)_

### 🔄 Battery Cycle Management

- Optional battery calibration reminders
- Suggests full **100% → 0%** discharge cycle every few days
- Smart scheduling system for healthy battery maintenance

### 💡 Brightness Controller

- Adjust system brightness directly from the app
- Quick brightness presets _(planned)_
- Auto brightness profiles _(planned)_

### 📊 System Monitoring

- Live CPU usage
- Memory usage monitoring
- Temperature monitoring _(platform support dependent)_
- Battery statistics
- Device health insights

### 🖥️ Minimal & Lightweight

- Clean and distraction-free interface
- Low resource usage
- Designed for everyday background usage

# 🚀 Why SystemZen?

Modern devices often stay plugged in for long periods, which may reduce battery lifespan over time. SystemZen helps users maintain healthier charging habits through intelligent reminders and monitoring tools.

The application is designed to act as a lightweight assistant for:

- Battery care
- Device health monitoring
- Brightness management
- Performance insights

# 📦 Installation

## Clone the repository

```bash
git clone git@github.com:SOUMITRO-SAHA/SystemZen.git
```

## Navigate to the project

```bash
cd SystemZen
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

# 🧠 Battery Health Tips

SystemZen encourages healthier charging habits:

- Avoid keeping battery at 100% continuously
- Try to maintain battery between 20%–80%
- Reduce excessive heat exposure
- Occasionally perform a full discharge cycle
